Wallet inventory

What every address holds, and what changed after you moved it.

This page never sees a seed, a phrase, or a private key. It takes addresses and reads public chain data about them. There is no field to type a phrase into. The rescue that does need one runs in a terminal, from a file at mode 600 — a browser page is the worst place a seed can be, and this one is deliberately not capable of using it.

Anything that is not an SP… / SM… principal is ignored, so you can paste a whole table and let it pick the addresses out. Hover a token for its amount and full contract; click "N more" on tokens or NFTs to expand the rest. The address is shortened — hover it for the full principal, and the saved snapshot always keeps it in full. Both are kept off screen so four hundred rows stay scannable. sBTC, xBTC, aeUSDC and USDC get their own columns and are matched on the exact contract, never the symbol — several tokens on Stacks claim the sBTC symbol and are not it.

Kept in this tab only — never stored, never sent anywhere but api.hiro.so. Without one you get roughly fifty requests a minute shared with everything else on your connection, which is enough for a handful of wallets and not for sixty. Each wallet costs two requests, plus one per BNS name.
