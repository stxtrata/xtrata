X Chess · on Stacks

Play a character

Ten chess personalities live on Bitcoin as permanent text. Pick one, point your own AI model at it, and play a real game against it.

What this actually is

Not a chess app with a bot in it.

Every character below exists as an inscription — a small permanent document on Bitcoin, via Stacks. It describes how that player thinks: what it wants from a position, when it will give up material, how it treats an endgame. Nothing else. It is not code and it holds no secrets.

When you play one, you supply the intelligence. Your script fetches the character's text, hands it to whichever model you like, and gets a move back. The character is the instructions; the model is the muscle. Two people running the same character on different models will get recognisably the same player making different decisions, which is the interesting part.

Every move goes on chain, so the game is a public record that neither side can revise afterwards.

The pips are search depth — how many extra moves ahead that seat looks, on top of what the shared engine already does. It is a handicap the tournament declared out loud, not a measure of strength. Two dots is the maximum anyone may be given.

Live records for all ten are on the board's Leaderboard tab: xtrata.xyz/i/3014. Ratings move as games finish, which is why they are not printed here.

What you need

Three things, and you probably have two of them.

A Stacks wallet with a small amount of STX — Xverse or Leather. A whole game costs a few pennies; see the costs below.

An AI model you can call. Anything that takes text and returns text. An API key, a local model, whatever you already use.

Node, or any way to run a script. The example below is about forty lines.

Set up the match

You play one side by hand on the board. Your script plays the character's side.

  1. Open the board and connect

    Go to xtrata.xyz/i/3014 and press Connect. The board is itself an inscription — there is no server, and it reads everything from the chain in front of you.

  2. Create a game with two named sides

    In the Play tab, set White to your own address and leave Black as anyone. That is the low-friction setup: your one wallet can play White because it is named, and Black because Black is open.

    If you would rather the record show two distinct players, make a second wallet and name it as Black instead. Both work; the second is tidier and costs one more account.

    Leave ranked off unless you want the result to touch the public ratings.

  3. Note the game number

    Opening the game gives it a number. Your script needs it, and it is also the whole of a shareable link: ?game=41.

  4. Point the script at your character

    Put the sheet's inscription number in the script below — 2999 for Plumb, 2995 for Gambit, and so on from the board above.

  5. Play

    Make your move on the board. Run the script; it reads the position, asks your model what the character would play, and submits it. Repeat. Each side pays its own transaction fee as it moves.

The script

Everything it needs comes off the chain except your model.

The prompt protocol is inscribed too. The house rules, the wording that fences the character off from the instructions, the way a position is described, and the rule that turns a reply back into a move — all of it is one small module on chain. Fetch it and you are asking the model exactly what the tournament asks it. Reimplement it and you are running a different experiment, which is fine, but it is a different one.

// Play one move as a character. Node 20+, no dependencies.

const XTRATA = 'https://xtrata.xyz/i/';
const SHEET    = 2999;   // Plumb. Any number from the board above.
const PROTOCOL = 2994;   // reads a sheet
const DIRECTOR = 0;      // prompt protocol — see the table below

const text = async (id) => (await fetch(XTRATA + id)).text();
const mod  = async (id) => import(
  'data:text/javascript;base64,' + Buffer.from(await text(id)).toString('base64')
);

const { parseEntry } = await mod(PROTOCOL);
const { SYSTEM_PROMPT, buildRequest, extractMove } = await mod(DIRECTOR);

const character = parseEntry(await text(SHEET)).entry;

// The position and the legal moves come from the board or your own
// copy of the engine — it is inscription 2991, also dependency-free.
const prompt = buildRequest({
  character: { prompt: character.style },
  fen, history, legalMoves, turn: 'black'
});

// Your model. Anything that takes two strings and returns one.
const reply = await yourModel(SYSTEM_PROMPT, prompt);
const move  = extractMove(reply, legalMoves);   // null if it answered badly

// Then submit `move` to the contract with your wallet, and set the
// fee to 400 uSTX — see the note on fees below.

If the model answers with a sentence instead of a move, extractMove returns null. Ask again. The house rules already tell it to reply with one move and nothing else, and most models obey; the ones that narrate tend to do it on the first move of a game and then settle.

What it costs

Measured on real games, not estimated.

0.0004STX per move
0.010STX to open a game
~0.02STX a whole game

Your wallet will suggest far more than this. Wallets estimate from network-wide traffic, not from this contract, and typically propose several times what a move actually needs. Set the fee yourself: in Xverse press Edit then Custom; in Leather use the Custom tab. Enter 400 uSTX. The board shows the same reminder in every game.

Write your own character

The ten are not special. They are ten sheets that happened to get inscribed first.

A character is a short text file: a name, a playing style, and optionally how it treats openings, risk, endgames and one quirk. Around twelve hundred characters in total. Fetch 2994, call blankEntry(), and it hands you the form with the limits written next to each field.

Inscribe it and it is permanent — which is the point. A character that can be edited after its games are played describes a player that never existed.

X Chess runs on Stacks and is inscribed with Xtrata. Games are refereed by a contract; results are derived by replaying the log, never taken from anybody's claim.

The full manual is at xtrata.xyz/i/3007.
