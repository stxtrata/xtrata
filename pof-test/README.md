# Proof of Free pre-inscription test deck

This directory contains a local test fixture for the Proof of Free recursive
collection before any immutable inscription or Drops v1.1 campaign is created.

## Contents

- `proof-of-free-master.html` — the Path A collection master generated by
  `xtrata-proof-of-free-collection-foundry-v4.8.html`.
- `index.html` — a small test deck linking to the complete master and a set of
  representative editions.
- `seeds/` — localhost-linked child wrappers for editions 1, 2, 100, 101, 512,
  1000, and 1024. These exercise the first editions, a chapter boundary, the
  midpoint, the end of the decimal trait core, and the final mosaic cell.

The child wrappers are test fixtures only. Production children must reference
the immutable on-chain master content URL, not the relative localhost URL used
here.

## Frozen test configuration

- Collection: `Proof of Free`
- Symbol: `POF`
- Supply: `1024`
- Mosaic: `32 × 32`
- Generator: `4.8.0`
- Master seed: `xtrata-proof-of-free-genesis-2026`
- Master SHA-256:
  `32bf7223783b2fa51c3da6721c29f4f5ab205a7fe13f21df3e280a1842b75009`

The hash identifies this exact test master. Any foundry setting change produces
different bytes and requires a new hash and another review.

## Run locally

From the repository root:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8765/pof-test/
```

The full collection master is available at
`/pof-test/proof-of-free-master.html`. A deterministic edition can be opened
directly with `?edition=N`, for example `?edition=512`.

## Verification performed

The master loaded in collection mode and rendered its mosaic. The seven child
wrappers loaded the same master with their assigned edition and returned the
expected collection name, master seed, chapter, visual engine, palette, sound,
and proof code.

Representative proof codes observed:

| Edition | Chapter | Proof code |
| ---: | --- | --- |
| 1 | Zero Receipt | `POF-0001-14E6YI4` |
| 100 | Zero Receipt | `POF-0100-0K2ZHW0` |
| 101 | Free Signal | `POF-0101-19K80GD` |
| 512 | No-Balance Badge | `POF-0512-1KJ5Y30` |
| 1000 | Proof of Free | `POF-1000-11Z0Q2U` |
| 1024 | Zero Receipt | `POF-1024-1TLHYQJ` |

## Decisions required before inscription

1. Editions 1001–1024 currently recycle the sound/chapter sequence after the
   1,000-edition decimal trait core. Consequently, edition 1024 is assigned to
   `Zero Receipt`. Confirm this is intentional or adjust the generator before
   freezing the production master.
2. The generated test master leaves Drop ID, Drops contract, and parent
   inscription metadata blank. Decide whether those values should be embedded
   before generating the production bytes.

## Production order

1. Resolve the decisions above and freeze all foundry settings.
2. Generate the production collection master and record its SHA-256 hash.
3. Test the production master with representative `?edition=N` values.
4. Inscribe the master first.
5. Put the master's resulting numeric Xtrata inscription ID into the Drops
   console's **Recursive engine inscription ID** field.
6. Create the immutable campaign with supply `1024` and all three claim rules
   enabled.
7. Generate production child wrappers using the master's permanent content URL
   and verify their hashes before inscription.
