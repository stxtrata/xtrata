How It Works

Three steps to permanent inscription.

01

Verify Canonical Hash

The helper contract stores the canonical content hash for each token. Your raw image bytes must match exactly.

02

Read URI, Fetch Raw Image

The UI reads the source token URI from chain, follows the metadata JSON, and extracts the raw image URL instead of guessing.

03

Inscribe and Swap

The Xtrata inscription is permanently bound to the Pepe, then holders can swap which side is liquid.
