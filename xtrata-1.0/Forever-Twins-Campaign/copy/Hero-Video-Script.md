# Hero Video Script

## 60-Second Version

### 0-5 Seconds

Narration: Your NFT might not actually contain the artwork.

Caption: Your NFT might not contain the art.

Shot: Close crop of a wallet NFT tile. The image fades to a broken placeholder.

### 5-15 Seconds

Narration: In many collections, the token points somewhere else: an IPFS gateway, a server, a marketplace URL, or a metadata endpoint. If that path breaks, the token stays in your wallet, but the art can disappear.

Caption: The token can survive while the artwork disappears.

Shot: Simple pointer diagram. Token on left. Link in middle. File/server/gateway on right.

### 15-25 Seconds

Narration: The scary part is that this can break temporarily and get quietly repaired. A marketplace or indexer re-caches it. A team switches gateways. Someone puts the picture back where the marketplace can find it.

Caption: A temporary blank image is a warning shot.

Shot: Broken image returns to normal, then flickers back to broken.

### 25-35 Seconds

Narration: This is what Forever Twins fix.

Caption: Forever Twins make the artwork permanent.

Shot: Xtrata inscription view or reconstruction page. Use real UI once available.

### 35-50 Seconds

Narration: Bitcoin Pepes are first. A Forever Twin gives your Pepe a permanent on-chain counterpart on Xtrata, built with Fak.fun. The original keeps its identity. The twin gives the art a durable on-chain home.

Caption: Original Pepe. Permanent twin. Bound pair. TBC final mechanics.

Shot: Claim flow screen capture from Fak.fun. Then Xtrata inscription view.

### 50-60 Seconds

Narration: The first 87 appear to be free, then 3 STX. Claim at Fak.fun. Powered by Xtrata.

Caption: First 87 free. Then 3 STX. TBC.

Shot: Claim CTA, count `TBC / 69`, final logo lockup.
