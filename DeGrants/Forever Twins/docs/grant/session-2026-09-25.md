## Core hash question

**Yes.** `mint-single-tx` recomputes the Xtrata rolling hash from the chunks and fails with u103
if it differs from the `content-hash` the helper passes from its record (u102 for wrong
lengths). The deployed mainnet core matches the repo copy in every relevant function. Details in
[../project/architecture.md](../project/architecture.md).
