# Xtrata bootcamp — production conventions

User preferences established during preparation of the opening film. Apply these when making subsequent lessons in this series.

1. Deliver clean video with no burned-in subtitles and no embedded subtitle stream. Keep editorial titles, source credits, inscription IDs and explanatory labels in the visuals.
2. Deliver subtitles separately as portable SRT and VTT files without forced placement. Supply a readable presenter script. A live-presenter track should use Jim’s voice and perspective in the writing; any generated narrator reference can have its own separately labelled transcript.
3. Supply a live version without the generated voice, a silent visual master, and an optional narrated rehearsal reference. Keep sound/music and narration available separately. All versions must share the same timebase and duration.
4. Align visual changes to spoken concepts, not arbitrary equal-length slots. Use speech markers for “picture / song / game,” definitions, named examples and chapter highlights. Explain that a live reading still needs rehearsal against fixed timings.
5. Use fresh primary inscription examples in each lesson. Avoid repeatedly showing the opening’s #296, #1107 and #3034 except for deliberate short callbacks.
6. Show exact inscription IDs, readable direct URLs, titles and confirmed creator credits. Maintain an audience link list and record the contract/network when needed to disambiguate an ID.
7. Keep a growing example catalogue with observed status, lesson fit, actions to demonstrate and checks still outstanding. Begin with `media/bootcamp-examples/catalogue.md`.
8. Capture real interfaces and interactions. Distinguish a prepared file from a completed inscription, an illustrative diagram from verified dependencies, and a replay from a live transaction.
9. Preserve original versions. Export revisions in a new version folder and document changes.
10. Verify duration/frame count, absence of embedded subtitles, representative rendered frames, complete media decoding and caption timing before delivery.
