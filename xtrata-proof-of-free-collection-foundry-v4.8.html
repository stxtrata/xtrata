Recursive collection master

1 master + 1,024 tiny children
The master inscription is immutable, so live ownership cannot be written back into it. Instead, it contains the entire renderer and mosaic explorer, embeds an optional registry snapshot, and can refresh ownership from a public JSON registry endpoint.
Each tiny child contains only its edition number and a full-screen recursive iframe pointing to this master URL with ?edition=N.
Accepted forms include an array, an object keyed by edition, or {"items":[...]}. Each item may contain: edition, claimed, inscription, contentUrl, owner, ownerName and tx.
The ZIP contains exactly 1,025 files inside inscriptions/: one master HTML and 1,024 deterministic seed children. Support manifests and instructions are kept separately and are not intended for inscription.
