Discovery tools, gateway & catalogue notes

Full import merges by inscription ID and preserves your annotations. The upstream snapshot is historical and may omit audio formats, video, embedded audio and recursive applications. Unknown-duration records stay in their own queue. The tool never executes inscribed HTML or JavaScript.

Measurement downloads one source at a time, with a 25-second timeout and 8 MB body limit. Failed decoding is recorded as an error, never as “not audio.” The optional local launcher fetches ordinals.com content through a same-origin route and retains a disk cache for repeat or offline auditioning. Gateway availability is still required for uncached content. If direct browser fetching fails, a native audio player is offered for listening only. It does not provide waveform analysis or precise region-looping.

Annotations are saved in this browser where storage is available. Use Save catalogue JSON for a portable backup, especially when opening this file directly.

Keyboard: Space = play/stop (outside form fields); N/P = next/previous. Opening the file performs no bulk audio download. Sources are fetched only when you load a clip, measure a queue or request a public import.
