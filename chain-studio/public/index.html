THE WORKBENCH

One idea. Every iteration.

Choose a sequence of models and reasoning levels. Each step gets the original request, the latest working prompt, recent evidence, and a copy of the previous output.

Snapshots stay separate. Inspect, preview, download, or test a completed version while the next model works.

Pause finishes the current step. Cancel stops the current agent. Feedback is included when the next stage starts.

Previews run without network access or browser storage. They support static HTML, CSS, and JavaScript. Apps requiring a server can be downloaded and run separately.

Token thresholds are checked between stages, so the final stage can exceed the threshold. Model availability is verified by Codex when each stage starts. No estimated dollar prices are invented.

Command tests run on disposable snapshot copies in the macOS sandbox, without network or inherited credentials. Use a test command that does not require installing dependencies.
