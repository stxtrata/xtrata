BEFORE YOU SETTLE IN

A few useful things to know.

What does each supported start cost?

The default is 0.000300 STX in network fees plus 0.000050 STX to the current song holder: 0.000350 STX total. Xtrata charges no platform fee. You can review the fixed network fee before enabling support; it never increases automatically. A paid start records a start, not a completed listen.

Where is my wallet kept?

On your computer, in the app’s data folder, separately from the installed app. The app manages the key for you. Losing those files can lose the balance; software with access to them can spend it. Keep around 1 STX here, rather than long-term savings. Higher balances are allowed, with a reminder.

Can I stop or take my money back?

Yes. Switch support off to keep listening free. Use Manage or return your balance in the app to review and send a return to your own address, less a network fee. Pending payments must be checked first. Closing the app stops new payments; an already submitted transaction may still confirm.

What happens when a payment is delayed?

Music carries on. Starts that cannot be paid stay free, with no catch-up charges. New eligible starts can pay when the outstanding transaction resolves. Support stays on until you stop or close the app; you approve it again next time.

I already use the local wizard. Is this the same wallet?

The desktop app uses its own wallet and does not silently copy your existing wizard wallet. Keep the old wizard files safe and return its funds before retiring it. Never delete a funded wallet folder. The original local lounge remains available while the desktop release is prepared.

The Open installed app link does nothing.

Install and open Xtrata Music first. You can always launch it directly from Applications or your Start menu. Your browser may ask permission to open the app. The link never approves payments.

Choose the standard universal download for macOS 13 or newer, or the Monterey preview for macOS 12. Both contain Intel and Apple-silicon versions. Windows 11

  1. Download the Windows EXE above and compare its SHA-256 with the value shown.
  2. Open the installer and follow its steps for your Windows user account. This is an unsigned preview; keep Windows security protections enabled.
  3. Open Xtrata Music and listen free first. No wallet extension or developer tools are needed. Support should be off after each restart.

For this first PC test, confirm free playback, artwork, looping and restart behaviour before funding the support wallet. See the Windows release and test evidence.

Mac

  1. Download the Mac disk image above, open it, and drag Xtrata Music into Applications.
  2. Open Xtrata Music. This preview is unsigned and not Apple-notarized. If macOS blocks it and you choose to test this download, use System Settings → Privacy & Security → Open Anyway for Xtrata Music. Do not disable system protections.
  3. Choose a song and listen free first. Check artwork, song details, playback and the public activity feed.
  4. To try support, fund the separate address shown in this app, refresh the balance, review the cost and turn support on.

Updating? Quit Xtrata Music, replace the app in Applications, then reopen it. Your desktop wallet is stored separately and is preserved. Enable support again when ready. No Node.js or extension is needed. Your developer wizard wallet remains separate.

MAC PREVIEW · LAST RESORT

If Open Anyway still does not work.

First verify that the downloaded DMG’s SHA-256 matches the value shown in its download card. If it matches and Xtrata Music is installed in Applications, this command removes quarantine from this app bundle:

xattr -dr com.apple.quarantine "/Applications/Xtrata Music.app"

This bypasses the normal Gatekeeper assessment for this copy of Xtrata Music. Try Privacy & Security → Open Anyway first. Do not add sudo, change the target to the Applications folder, or use this for a download whose checksum does not match. Signed and notarized releases will not need this fallback.
