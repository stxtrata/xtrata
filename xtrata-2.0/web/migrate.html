Migrate inscriptions to v3

Your inscriptions themselves never move or change — migration mints the same token id on the current v3 core (xtrata-v3-2-3) and retires the legacy token into escrow. One small signed transaction per token. It never asks for a seed phrase.

How it works — quote first

  1. Connect the wallet that holds your legacy (v1/v2) inscriptions.
  2. Scan & quote — every known legacy source is checked together. Direct holdings and active listings on registered Xtrata markets are classified; blocked or unreadable items stay visible with an explanation.
  3. Review the live protocol fee, mining allowance and estimated total. Scanning creates no wallet and requests no funds.
  4. Migrate only when ready — one token at a time, or Migrate all ready (one wallet signature each; the next opens after the previous confirms).

The 0.005 STX per-token amount is the mining-fee allowance, not the whole migration cost. The page reads the separate migration protocol fee from the live v3 contract and itemises both before you sign.
