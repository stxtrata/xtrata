Migrate inscriptions to v3

Your inscriptions themselves never move or change — migration mints the same token id on the current v3 core (xtrata-v3-2-3) and retires the legacy token into escrow. One small signed transaction per token. It never asks for a seed phrase.

How it works — three steps

  1. Connect the wallet that holds your legacy (v1/v2) inscriptions.
  2. Scan — pick a source core and press Scan. Eligible tokens appear live as they're found; anything already on v3 is skipped automatically. Press Scan again to stop at any time.
  3. Migrate — one token at a time, or Migrate all (one wallet signature each; the next signature only opens after the previous one confirms on-chain, so nothing can double-fire).

Cost: a fixed 0.005 STX network fee per token (if your wallet suggests more, set it to 0.005 manually). Confirmations usually land in seconds-to-minutes; the activity log below tells you exactly what's happening the whole time, and anything that stalls, drops, or fails is reported with what to do next — this page never hangs silently.
