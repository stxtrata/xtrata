SNES Arcade harness

The real emulator, the Arcade wrapper's loading logic and a pretend chain, all inside this page. No wallet, no network, no cost, nothing deployed. Pick a game from the emulator's Games menu (loads from a mock inscription through the catalogue), use the emulator's own Load ROM for a local file, or open any inscription by its number. Then change the catalogue on the right and watch the menu follow.

Controls (default keys)

Arrows = D-pad · Z = B · X = A · A = Y · S = X · Q = L · W = R · Enter = Start · Shift = Select · P pause · M mute · Tab fast-forward. Keys can be rebound in the emulator's Controls tab; this card shows the defaults only. On touch screens use the on-screen pad.

Open by inscription ID

Any sealed inscription number on the core. If its bytes match a registered game it is treated as that game (same scoreboard); otherwise it is unlisted: play only, no scores. The emulator is never told "verified" for an ID.

What the wrapper did
Publish and manage (act as someone)

You are the catalogue admin and a publisher. A publisher's games land on the Community tab; the admin's land on Core. A stranger is refused.
