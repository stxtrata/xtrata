SNES catalogue launch canary

Takes the on-chain SNES game catalogue from nothing to a registered, emulator-tested state in the only safe order. It deploys the catalogue contract and the Xtrata adapter, inscribes each game's ROM and artwork on Xtrata core v3.2.3 and reads every byte back, then registers the games, proves duplicates, wrong sizes and strangers are refused, and finally loads every game into the real emulator through the contract, and again from local ROM files. Each step unlocks only when the one before it has passed, and each re-reads the chain rather than trusting this page. Mainnet only.

Wallet extensions do not inject into file:// pages. Serve this folder instead: python3 -m http.server 8080, then open http://localhost:8080/snes-catalogue-canary.html.
