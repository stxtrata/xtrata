Arcade leaderboard v2 canary

Deploys xtrata-arcade-scores-v2 from your web wallet and proves it on chain: a real Astro Blaster 3 run flown under your address is submitted and re-verified from the stored replay, the same run sent from a throwaway wallet is refused, void and ban work, and the test board is closed again. The last step registers the production boards once the game is inscribed. Run the steps from top to bottom; each unlocks only when the one before it has passed, and each re-reads the chain rather than trusting this page's memory.

Wallet extensions do not inject into file:// pages. Serve this folder instead: python3 -m http.server 8080, then open http://localhost:8080/arcade-scores-v2-canary.html.
