Somewhere Else inscriber

Inscribes the 24 images, then the article, then the reader, from a temporary wallet this page creates. You fund it by hand once, you never sign anything, and at the end all 26 inscriptions and the leftover STX go to your own wallet. Each step re-reads the chain, so a stopped run resumes without re-sending anything.

Serve this file over http rather than opening it from disk if the browser blocks storage: python3 -m http.server 8080, then open http://localhost:8080/.
