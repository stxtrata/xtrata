Deploys a fresh v1.7 collection helper from your web wallet, configures a one-file collection, mints it from a throwaway collector at the fixed price, and sweeps everything back. Run the steps from top to bottom. Each step unlocks only when the one before it has passed, and each re-reads the chain rather than trusting this page's memory.
