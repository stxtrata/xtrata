WHAT THIS PROVES

  1. Your device can make a passkey that supports PRF.
  2. PRF hands back the same 32-byte secret every time — across taps, and across a page reload.
  3. That secret can lock and unlock a wallet seed (encrypt → decrypt → identical).
If all three pass on iPhone, iPad, Safari and Chrome, the self-hosted passkey wallet is viable. If test 2 fails anywhere, that device can never use it.
