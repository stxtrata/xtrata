YOUR MUSIC SUPPORT WALLET

Settle in, step by step.

  1. Install the companion. Download desktop setup. Extract the source package and run node setup.mjs then npm run music:lounge, then start it. Node.js 24 is required. Keep its folder safe.
  2. Add the Chrome extension. Open chrome://extensions, enable Developer mode, choose Load unpacked, then select extensions/music-support inside the extracted package. Reload this lounge afterwards. This is an early-access unpacked extension, not a Chrome Store release.
  3. Connect this browser. Select Connect below and approve the connection in the local companion window.

Compatibility & what to expect

Desktop Chrome with the local companion is the initial target. macOS companion playback has been tested; Windows/Linux remain experimental. Phones cannot run this wallet. You can always listen free.

Keys stay on your computer. We recommend around 1 STX, because local software with access to wallet files can spend it. No cloud recovery. The website never receives your signing key. Approve spending in the local companion: continuous support can use your available balance.

Keep the companion and browser running. Disconnection, reload, Stop or two minutes without a website check-in ends web support. An uncertain payment blocks new payments; missed starts stay free and are not charged later. A paid start is not proof of a complete listen.
