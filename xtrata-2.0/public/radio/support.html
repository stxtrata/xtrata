You stay in control

We recommend funding with 1 STX on Stacks mainnet. You can add more; higher balances do not block payments. The default cost is 0.000350 STX per paid start: 0.000300 network fee + 0.000050 to the current master holder. No Xtrata platform fee.

You can review the fixed fee before enabling support. It never rises automatically. Continuous support can spend the available balance until another start cannot be afforded.

Free listening is always an option. Buying support is not required to hear the music.

Will it run on my computer?

The desktop companion needs Node.js 24, npm, an internet connection and a browser with the song’s audio codec. Node provides builds for macOS, Windows and Linux; that does not mean this app is fully verified on every system. Get the official Node.js runtime ↗

Get set up in four steps

  1. Install Node.js 24. Use the official download, then reopen your terminal.
  2. Download and extract the setup package. Put the extracted xtrata-music-support folder somewhere permanent, such as Documents. Don’t run it inside the archive or a temporary folder.
  3. Install dependencies. On Mac, run Install.command; on Windows, run Install.cmd. Or open a terminal in that folder and run node setup.mjs. Setup downloads npm dependencies. It does not create a wallet or send funds. If your system blocks the launcher, use the terminal command; don’t disable system protections.
  4. Start the companion. Use Start.command / Start.cmd, or run npm run music:lounge. Keep that terminal open, then open your local listening room ↗.
Terminal commands (from the extracted folder)
node setup.mjs
npm run music:lounge

Windows can extract a .tar.gz using a compatible archive tool or tar -xzf xtrata-music-support.tar.gz. Setup needs Node 24 on your PATH. If port 8798 is in use, an existing companion may already be running: open the listening room instead of launching a second copy.

Prefer the website lounge? In Chrome, open chrome://extensions, enable Developer mode, select Load unpacked and choose extensions/music-support inside your extracted package. Open or reload the public listening room, select Connect desktop wallet, and approve the connection in the local companion. The extension currently supports the main xtrata.xyz lounge only, not preview sites.

In the lounge, choose Create my support wallet, copy its address, fund it using your usual wallet, then refresh the balance. Only turn on support when you’re ready. Funding alone never enables payments.

What it cannot do

  • It cannot keep paying while your computer is asleep, offline or the companion is stopped.
  • It supports the local lounge and the public listening room at xtrata.xyz/radio/lounge with the included Chrome extension. Other pages and embeds stay free.
  • It does not prove a full listen, a unique person or a tournament vote. It records an eligible start.
  • It does not pay the original artist if someone else currently holds the master.
  • It cannot promise every start is paid. Pending payments or network trouble leave starts free, with no catch-up charges.
  • It does not provide cloud recovery, device sync, automatic updates or a signed native installer.

Know where your wallet lives

The companion stores its signing key automatically in its local .artifacts/radio-wizard folder. The encrypted key and its unlocking material live on the same computer. This is a small spending wallet, not secure long-term storage.

We recommend keeping no more than 1 STX here. Anyone or any software with access to those files may be able to spend the funds. Deleting the app folder can lose your wallet. Do not share it or put it in a public repository.

Use Manage or return your balance before removing the app. Return transactions cost a network fee and require unresolved payments to be checked first. Never replace or delete a funded installation when trying a new download.

Leave it playing. Know when support stops.

With continuous support enabled, the companion checks new starts and automatically tries payment checks again after temporary problems. It never blindly resubmits an uncertain transaction. Stop, closing or reloading the lounge, changing settings, or restarting the companion requires a new approval. If you add funds while continuous support remains enabled, later starts can pay again.

Keep your computer awake, the companion running and the lounge open. The public lounge connects through the included Chrome extension after you approve locally. It cannot access your signing key or withdraw funds. Two minutes without a website check-in ends web support.
