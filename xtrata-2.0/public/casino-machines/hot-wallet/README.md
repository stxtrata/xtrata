# Hot Wallet (machine #25, "The Heist Museum")

A standalone, drop-in ParallaX Casino fruit machine. Every tile on the reels is an exhibit in a museum of real exchange hacks,
2011 to 2026, with its date, the figure reported at the time, one plain line on how it happened, a lesson and sources.
Block Fortune v2 engine byte for byte (sha256 `7a5ae8482d70f1e09b7308103c52eb738f8e12a1fae36b9832488000a4f7b98e`), RTP 94.38%.
Accent `#e11d48`. Machine id `hw`, game id `hot-wallet`. **Not placed in the casino; no casino file was edited.**

Open `index.html` over http (for example `python3 -m http.server` in this folder's parent) for the test page: the 3D cabinet,
the deck buttons, the vault-door lever, Full screen, the Test panel and the Bonus Lab (key L).

| Path | What it is |
| --- | --- |
| `index.html` | The standalone test page (studio, cabinet view / screen view, Test, Full screen). |
| `pack.json`, `pack.js` | The machine pack: `{name, description, color, accent, model, game, css}` (`pack.js` is the same as `window.HW_PACK` for the test page). |
| `dist/hot-wallet.html` | The built game document (the `game` field of the pack, ungzipped). |
| `src/game.js` | The game: engine (unchanged), museum tiles, scenes, panels, fullscreen bar, Bonus Lab, holder layer, room API. |
| `src/cabinet.js`, `src/model.json` | The cabinet source and its packed model; `NOTES-cabinet.md` documents every role. |
| `art/` | `facts.json` (generated by `_gen_facts.py`), `facts.js`, `sources.json`, `FACTS-NOTES.md`, `coins/` (official BTC and ETH symbol files). |
| `tools/` | `build.mjs` (pack), `build-art.mjs`, `build-cabinet.mjs`, `rtp-sim.cjs`, `exact-rtp.py`, `test-page.cjs`. |
| `vendor/` | The room's shared test stubs and renderers, copied unmodified. |
| `INTEGRATION.md` | How to place it on the casino floor. |
| `TEST-RESULTS.md` | What was run and what passed. |

## Rebuild

```
python3 -I art/_gen_facts.py && node tools/build-art.mjs
node tools/build-cabinet.mjs            # only if src/cabinet.js changed (headless Chromium, ~20 s)
PX_CASINO_HTML=/path/to/xtrata-2.0/public/casino/index.html node tools/build.mjs
node tools/rtp-sim.cjs 5000000          # RTP simulation (+ engine hash)
python3 tools/exact-rtp.py              # exact RTP
node tools/test-page.cjs http://localhost:8102/hot-wallet/index.html dist/test
```
