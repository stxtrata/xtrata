This is a real 3D room, not a panorama. The furniture has collision, the screen is live, and all room assets are included in this file. On touchscreens, move with the left stick and drag the room to look.

Pixel Quest is an original miniature platform game included to demonstrate the live screen. It is not a SNES emulator and contains no ROMs. Your existing emulator can supply its canvas and input adapter through BasementLounge.attachEmulator().
