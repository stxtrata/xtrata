Xtrata

Report abuse or a security problem

Xtrata is a permissionless protocol: anyone can inscribe a file on Stacks. If something served through xtrata.xyz is harmful, we want to hear about it.

How to report

Send a direct message to @XtrataLayers on X.

Please include

  • The inscription id, or the full link (for example https://xtrata.xyz/x/1234 or /i/1234).
  • What it does and why you think it is harmful: phishing, malware, scam, impersonation, illegal content, or a security flaw in the site itself.
  • How to see it for yourself, and any screenshots. Please do not send anything that is itself illegal.

About inscriptions

Inscriptions are permanent on the Stacks blockchain and nobody can delete them.

Direct links to raw inscription pages are served in a restricted sandbox so that scripts inside an inscription cannot act as xtrata.xyz.

Security researchers

Machine-readable contact details are at /.well-known/security.txt. Please give us a reasonable chance to fix a problem before you publish it.
