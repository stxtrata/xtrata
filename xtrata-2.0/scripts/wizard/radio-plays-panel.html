Radio backend wizard · MAINNET

This wizard signs on your computer’s backend. No browser wallet, extension or private key is used by this page.

1. Get the address

Send your test funding to the address below using Stacks mainnet. Funding never starts a test.

2. Confirm funding

Ready. Create or retrieve the dedicated wizard address.

3. Approve an automated test run

Every transaction pays 0.00005 STX to the master holder plus the fixed fee you choose. The default is 300 microSTX (0.0003 STX). 200 microSTX may be rejected. No fee increases automatically.

Maximum five tests per run, 0.005 STX per run, 0.01 STX lifetime test spending and a 0.001 STX balance reserve. Failed or uncertain transactions stop the runner. This tests contract payments, not audio playback.

Keep this backend process running. Stop cannot reverse submitted transactions. Back up the entire local .artifacts/radio-wizard folder securely; it contains both the encrypted wallet and its local unlock key. Access to both allows spending. No personal or deployer wallet is used.
