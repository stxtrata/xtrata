XTRATA MUSIC · EARLY ACCESS

Start listening
in three steps.

If the Xtrata Music hub offers a signed installer for your computer, use that. It is the easiest route and needs no Node.js or terminal. These instructions are for the fallback source package.

1

Move the extracted xtrata-music-support folder into Documents.

2

Install Node.js 24 LTS from the official site if you do not already have it.

3

Open the folder and double-click:
START HERE - Mac.command
or START HERE - Windows.cmd

The first launch installs the required files and opens your listening room. Later launches open it directly. Keep the terminal window open while listening.

Mac security message

Control-click the START HERE file, choose Open, check the filename, then choose Open. If needed, use System Settings → Privacy & Security → Open Anyway for this exact file. Never disable Mac security globally.

First use

  1. Select Create my support wallet.
  2. Copy the funding address shown in the listening room.
  3. Send about 1 STX on Stacks mainnet from your usual wallet.
  4. Refresh the balance.
  5. Play music free, or read the payment details and explicitly turn support on.

Funding never turns payments on. Xtrata charges no platform fee. At the default setting, an eligible start costs 0.000350 STX total.

Using an AI assistant

This package includes AI AGENT - INSTALL.md and a reusable skill at skills/xtrata-music-support-installer/SKILL.md. Give the guide to an assistant and ask it to install and validate Xtrata Music. The guide lets it handle the technical setup while keeping wallet funding and Music Support under your separate control.

Keep your wallet safe

Your small support wallet is stored separately in your computer's application-data folder. Do not delete or share those files. There is no cloud recovery. Keep around 1 STX here rather than long-term savings. Return the funds from inside the listening room before removing the app.

Troubleshooting

The browser did not open

Keep the terminal open and visit http://127.0.0.1:8798/lounge.

Node.js is missing

Install Node.js 24 LTS from the official link above, then double-click START HERE again.

Installation stopped

Check your internet connection, close other Xtrata Music windows, and try START HERE once more.

Full safety, updating and troubleshooting instructions are in README.md. Latest information: Xtrata Music hub.
