XTRATA MUSIC · EARLY ACCESS

Start listening
in three steps.

Use the Xtrata Music Lounge first. A desktop installer is the simplest route when one is available. This source package is a Mac/Linux fallback; on Windows it only opens the Lounge because a Windows support wallet needs the desktop app's built-in Windows protection.

1

Move the extracted xtrata-music-support folder into Documents.

2

On Mac or Linux, install Node.js 24 LTS from the official site if needed.

3

On Mac, double-click START HERE - Mac.command. On Linux, use START HERE - Linux.sh. On Windows, START HERE - Windows.cmd opens the Lounge and never creates a wallet.

The Mac/Linux first launch installs the required files and opens a local listening room. Keep its terminal window open while listening.

Windows

Use the Windows 11 x64 Xtrata Music desktop preview when it is published in the Lounge. It uses Electron safeStorage and Windows DPAPI for its local wallet. Do not use this source package to create a Windows support wallet and do not disable Windows security protections.

First use

  1. In a supported local companion or desktop app, select Create my support wallet.
  2. Copy the public funding address and send about 1 STX on Stacks mainnet from your usual wallet.
  3. Refresh the balance.
  4. Play music free, or read the payment details and explicitly turn support on.

Funding never turns payments on. Xtrata charges no platform fee. At the default setting, an eligible start costs 0.000350 STX total.

Using an AI assistant

This package includes AI AGENT - INSTALL.md and a reusable skill at skills/xtrata-music-support-installer/SKILL.md. They keep installation separate from wallet funding and Music Support approval.

Keep your wallet safe

Your small support wallet is stored separately in your computer's application-data folder. Do not delete or share those files. There is no cloud recovery. Keep around 1 STX here rather than long-term savings. Return funds from inside the listening room before removing the app.

Troubleshooting

The browser did not open

Keep the Mac/Linux terminal open and visit http://127.0.0.1:8798/lounge.

Node.js is missing

Install Node.js 24 LTS from the official link above, then double-click the Mac or Linux launcher again.

Installation stopped

Check your internet connection, close other Xtrata Music windows, and try once more.

Full safety, updating and troubleshooting instructions are in README.md. Latest information: Xtrata Music Lounge.
