What is Forever Twins?

Updated 6 October 2026

The problem

When you own most NFTs, the blockchain records a token number and a link. The artwork itself usually sits somewhere else: on IPFS, on a company’s server, in a cloud bucket. If the pinning lapses, the team moves on or the server shuts down, the token still exists but the link points at nothing. The art is gone and there is no undo.

The idea

Forever Twins creates a twin of an NFT: a new token whose artwork is stored in full on the Stacks blockchain through Xtrata, byte for byte. Nothing about the twin depends on a server staying online. The original NFT is never changed. The twin sits next to it.

How it works

  1. Each collection gets its own helper contract. Before anyone can use it, the helper holds a record for every token: the fingerprint (hash) of the art, its file type and size, and the token’s metadata link. The record is then locked for good, so the helper can only ever create faithful twins of that collection’s art. The full list of fingerprints (the manifest) is public, and its own fingerprint is stored in the contract.
  2. Anyone can create a twin. They pay the helper’s fee plus the cost of storing the art on-chain. The helper checks the art against the locked record before it accepts it. The new twin is held by the helper.
  3. A holder swaps their original for its twin. The helper takes the original into safe keeping and the holder receives the twin. Swapping is free apart from the network fee.
  4. Whoever holds the twin can swap back. They return the twin and receive the original. One side of every pair is always in the helper: if the twin is in your wallet, the original is in the helper, and the other way round. Nobody can pause or block a swap.

Paying for a twin gives no right to the original. It only puts the art on-chain.

What keeps it honest

  • The art in a twin must match the locked fingerprint for that token. The contract refuses anything else.
  • Swaps check real ownership in both contracts, before and after each move.
  • The helper’s owner cannot pause swaps, change the record, move a paired token, or change who is paid. After the record is finalised the owner can only set the fee (within a ceiling fixed at deployment), rescue a token that was sent to the helper by mistake (announced on-chain first, with a delay of about three days), and hand ownership to a new address in two steps.
  • Anyone can check all of this without trusting us. See Verify it yourself.

Reading the numbers on a collection page

A helper being live does not mean every token in the collection has a twin. Twins are made token by token, so each collection page shows four separate numbers:

RecoveredTokens whose art was fetched and fingerprinted when the manifest was built.
Seeded on-chainRecords written into the helper.
Inscribed twinsTokens that now have a twin on-chain.
Swap-readyTwins whose swap is open.

What it costs

  • A flat fee per twin, set by the helper’s owner and shown on the collection page and in the contract (get-fee). It is split equally between two payee addresses fixed at deployment. It is currently 1 STX on Megapont Ape Club and Bitcoin Monkeys and 0.1 STX on NYC Degens. The three older helpers have their own fees, shown on their pages.
  • The Xtrata cost of storing the art, which depends on file size. The page quotes it before you confirm.
  • Swaps in either direction are free.

Files over 512 KB cannot be inscribed in one transaction. For collections set up for it, the page offers a guided route using a temporary wallet: it shows the amount to send, runs the uploads, creates the twin and returns what is left. A 5% processing fee goes to Xtrata, and only if the twin is actually made.

What Forever Twins does not do

  • It does not fix or repoint the original NFT’s links, and it does not say a collection is broken.
  • It does not preserve more than the manifest covers: art at the time the manifest was built, not later changes to the collection.
  • The contracts are an unaudited prototype. Read the code and the tests before relying on them.
One important warning. Always use a collection page (or call the helper’s swap functions yourself). Never send your NFT directly to a helper’s address. The contract cannot tell who sent it, so it cannot simply give it back. A slow, public rescue exists for these mistakes, but it cannot be guaranteed forever.
