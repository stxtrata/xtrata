Stacks NFT Preservation Census

Where the art behind the top 250 Stacks NFT collections actually lives, and whether you can still reach it. Each collection was checked twice: once by following the link written in its smart contract, and once by loading the images Gamma's marketplace shows.

Two ways to find the art

Layer 1 · the contract
contract→get-token-uri→metadata file→image

The only route that belongs to the token itself. If any link in this chain is gone, the NFT no longer points at its art.

Layer 2 · the marketplace index
Gamma database→its own image copy

Gamma keeps its own record of each token's image, mostly on its old "stxnft" Pinata account. When layer 1 dies, this copy is often the only thing still showing the art.

How this was measured

  • Collections: Gamma's all-time volume ranking for Stacks, top 250.
  • Contract layer: contract source and get-token-uri read through the Hiro API for up to four tokens per collection; metadata and image fetched as written, then through three IPFS gateways (Filebase, Pinata public, Gamma's Pinata).
  • Marketplace layer: up to 16 tokens per collection loaded from the image addresses Gamma serves; failures re-tested slowly.
  • IPFS hosting: the public IPFS routing service was asked which machines still store each folder.
  • This is a sample, not a full scan of every token. A collection marked "Failing" may have more or fewer broken tokens than the sample shows.
  • Results are a snapshot from one run on one day, from one network. Servers that were briefly down will look dead. Repeat runs are the way to confirm.
  • "Pinata only" means only Pinata machines answered for that content. It says nothing about how long Pinata will keep it.
  • Ratings describe reachability, not the value or legitimacy of any collection.
